# Práctica 2 — Funciones y procedimientos

## Objetivos

- Modularizar un programa dividiéndolo en procedimientos (`procedure`) y funciones (`function`).
- Distinguir parámetros **por valor** de parámetros **por referencia** (`var`) y sus efectos al llamar al módulo.
- Entender el alcance (*scope*) de las variables: qué variable "gana" cuando una variable local tiene el mismo nombre que una global.
- Reconocer errores comunes al declarar y llamar módulos (encabezados mal formados, tipos que no coinciden, pasar una constante donde se espera una variable `var`).
