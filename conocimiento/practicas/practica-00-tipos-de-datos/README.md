# Práctica 0 — Introducción a la programación / Tipos de datos

## Objetivos

- Escribir programas Pascal mínimos (`program`, `var`, `begin...end.`) que lean datos por teclado y escriban resultados en pantalla.
- Usar los tipos de datos simples `integer` y `real` para representar cantidades enteras y con decimales.
- Construir expresiones aritméticas básicas (`+`, `-`, `*`, `/`, `div`, `mod`) y entender por qué `div`/`mod` sólo están definidos entre enteros.
- Controlar el formato de salida de números reales con la notación `writeln(X:Y:Z)`.

## Prerrequisitos

Ninguno: esta es la primera práctica de la cursada histórica ("Practicas") de CADP.
