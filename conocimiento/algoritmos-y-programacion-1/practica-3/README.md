# Práctica 3 — Introducción a la programación III (Bucles)

## Objetivos

- Usar la estructura de control repetitiva `while` (precondicional, cantidad de repeticiones desconocida de antemano).
- Usar la estructura de control repetitiva `for` (cantidad de repeticiones fija y conocida).
- Combinar acumuladores y contadores con estructuras repetitivas para calcular sumas, promedios y porcentajes.

## Prerrequisitos

[Práctica 2 — Introducción a la programación II](../practica-2/README.md): tipo `boolean` y estructura `if`.
